Klee Sync — User Guide
What is Klee Sync?

Klee Sync is an eXist-db application with two functions:

  • Conversion — converts Euporia XML files to TEI XML via XSLT.
  • Alignments — stores and versions TEI alignment files produced by DiScEPT.
Alignments tab

Creating a project

Type a name in the New project name field and click . A project is a named container for versions of a TEI alignment file.

Saving an alignment

Click Save alignment in the toolbar. Select the destination project, then either upload a .xml file or paste the TEI content. Each save creates a timestamped version in the project history.

Version history

Select a project to see its version list on the left. Click any version to preview the XML on the right. The latest badge marks the most recent save.

Restoring a version

Preview a past version, then click Restore. The selected version becomes the new current version and a new history entry is created.

Downloading

Download current downloads the latest saved file. The button in the preview panel downloads whichever version is currently shown.

Deleting a project

Click Delete project to permanently remove the project and all its versions. This action cannot be undone.

Integration with DiScEPT

To use Klee Sync as the save/load target from DiScEPT, configure the eXistDB Sync dialog in DiScEPT as follows:

Base URLhttp://<host>:8080/exist
Collection/db/apps/klee-sync/data/alignments
Useryour eXist-db username
Passwordyour eXist-db password
Proxy URLhttp://localhost:3001 (if using DiScEPT proxy: any port might suit)

With this configuration:

  • Load fetches the current version of the selected project into DiScEPT.
  • Save automatically stores a new timestamped version in Klee Sync.
Backup & Restore

Backup downloads a .zip archive containing all projects and all their versions. Use this before upgrading Klee Sync to a new XAR version.

Restore uploads a previously downloaded backup ZIP and re-imports every version of every project in chronological order.

Conversion tab

Upload an Euporia .xml file using the file picker. Klee Sync sends it to the server-side XSLT transformer and displays the resulting TEI XML alongside the source. Click Download TEI to save the output. Use Sync to fetch the source XML directly from a remote URL instead of uploading a file.
