Klee Sync — User Guide
What is Klee Sync?

An eXist-db application that works as a versioned repository for TEI alignment files produced by DiScEPT, plus an Euporia → TEI XML converter.

Alignments

Versioned storage for DiScEPT projects

Conversion

Euporia XML → TEI XML via XSLT

Working with Alignments
1
Create a project Type a name in the sidebar field and click +. A project holds all versions of one alignment file.
2
Save an alignment Click Save alignment in the toolbar. Upload a .xml file or paste TEI content. Every save is stored as a new timestamped version — nothing is ever overwritten.
3
Browse version history Select a project to see its full history. The latest badge marks the most recent version. Click any row to preview its XML.
4
Restore a past version Preview any older version, then click Restore. That version becomes the new current — and a new history entry is created, so you never lose work.
5
Download Download current in the project header saves the latest file. The button in the preview panel saves the version currently shown.
6
Delete a project Click Delete to permanently remove the project and all its versions. This cannot be undone.
DiScEPT Integration

Configure the eXistDB Sync dialog in DiScEPT to point at Klee Sync. After loading a project, any Save in DiScEPT automatically creates a new version — exactly like a Git commit.

Field Value
Base URL http://<your-host>:8080/exist
Collection /db/apps/klee-sync/data/alignments
User your eXist-db username
Password your eXist-db password
Proxy URL http://localhost:3001 (if using DiScEPT proxy server)
After a Load, the green session banner appears at the top of the page. Every subsequent Save in DiScEPT creates a new version of that project automatically.
Backup & Restore
Backup

Downloads a .zip with all projects and all their versions. Run a backup before installing a new XAR version.

Restore

Upload a backup ZIP to re-import all projects and versions in chronological order. A progress bar shows the status.

Conversion tab

Upload an Euporia .xml file — Klee Sync converts it server-side via XSLT and displays the TEI result alongside the source. Click Download TEI to save the output. Use Sync to fetch the source directly from a remote URL.
